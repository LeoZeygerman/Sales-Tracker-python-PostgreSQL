Sales Tracker

CLI-приложение для управления товарами и отслеживания продаж и покупок.

Проект написан на Python и использует PostgreSQL для хранения данных.

Возможности

* ➕ Добавление нового товара
* 🔍 Поиск товара:
    * по ID
    * по имени
* 📦 Просмотр всех товаров
* 🔄 Изменение количества товара:
    * продажа товара
    * покупка товара
* 📊 Автоматическое обновление общего количества товара после продажи или покупки
* 🗂️ Сохранение каждой операции в отдельную таблицу
* 📜 Просмотр истории продаж
* ❌ Удаление товара
* 🚪 Выход из приложения

Как работает изменение количества

Каждая продажа или покупка сохраняется в отдельной таблице истории.

При продаже количество товара уменьшается:

Количество товара - количество продажи

При покупке количество товара увеличивается:

Количество товара + количество покупки

При этом операция сохраняется в истории, благодаря чему можно посмотреть предыдущие продажи и изменения количества товара.

База данных

Проект использует PostgreSQL для хранения информации о товарах и истории операций.

Основные данные:

* товары;
* количество товара на складе;
* история продаж и покупок.

История операций хранится отдельно от основной таблицы товаров, поэтому можно отслеживать изменения количества товара.

Установка

1. Клонирование репозитория

git clone <URL_РЕПОЗИТОРИЯ>
cd sales-tracker

2. Создание виртуального окружения

Windows:

python -m venv .venv

Активация:

.venv\Scripts\activate

3. Установка зависимости

pip install psycopg2

4. Настройка PostgreSQL

Создайте базу данных PostgreSQL и укажите параметры подключения в database.py:

host = "localhost"
database = "sales-tracker"
user = "postgres"
password = "YOUR_PASSWORD"
port = "5432"

5. Запуск

python main.py

Главное меню

После запуска приложение предоставляет основные операции:

1. Добавить товар
2. Найти товар
3. Показать все товары
4. Изменить количество товара
5. Удалить товар
6. Посмотреть историю продаж
7. Выйти

Пример работы

Добавление товара:

Название товара: Apple
Количество: 50
Товар успешно добавлен.

Продажа товара:

Товар: Apple
Количество продажи: 5
Продажа успешно добавлена.
Остаток товара: 45

Покупка товара:

Товар: Apple
Количество покупки: 20
Покупка успешно добавлена.
Остаток товара: 65

История операций позволяет увидеть предыдущие продажи и покупки.
